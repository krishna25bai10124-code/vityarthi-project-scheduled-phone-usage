# vityarthi-project-scheduled-phone-usage

## Introduction

Nowadays, phones have kind of become a part of our daily routine. We use them for everything namely studying, chatting, watching videos, and even when we’re bored. But the problem is, most of the time we don’t even realize how much time we are actually spending on our mobiles. What starts as "just 5 minutes" easily turns into an hour or more.
This project is a small attempt to deal with that issue. It is not something very advanced, but it tries to bring a bit of discipline by allowing phone usage only during fixed time periods. The idea is simple, if you decide when to use your phone beforehand, you're less likely to get distracted at random times.
I made this project using basic Python, mainly focusing on logic rather than complexity, so that even beginners can understand it.

## What This Project Does

This  project is a very simple and basic system to help control how often we use our phones. The main idea came from a very common and relatable problem, picking up our phone again and again without even realizing how much time is being wasted. The concept behind it is not to completely block usage, but to make it more intentional and productive.
What this program does is actually pretty straightforward. It asks you to set a time range like for example from 6 PM to 8 PM, and that becomes your "allowed" phone usage time. After that, the program checks the current time on your system and compares it with what you had entered earlier.
If the time matches your allowed slot, it tells you that you can use your phone. But if it’s outside that time, it gives you a small warning message like “not allowed” or “stay focused”.
It’s not something that forcefully blocks your phone or anything similar to that. It is like a reminder system. 
Honestly, I think it’s a small idea, but it connects really well to our real as well as our daily life, especially for students.

## How to Use It

This program is easy to use and doesn't require much effort. Basically, when you run it, the first thing the program does is asking you to enter a start time and an end time.
For example, if one enters 18 as start time and 20 as end time, the program allows phone usage between 6 p.m. and 8 p.m.
The program automatically determines your current system time after you enter these values. It provides you with the outcome based on that.
It will display something like "you can use your phone now" if the time is within your permitted range. However, it will show a warning message advising you to stay focused and refrain from using it if it is outside the range.
you can also change the time slots whenever you want depending on your schedule. For example, you might permit use in the evening but prohibit it during study sessions.
It is very flexible, even though the logic is basic and simple.
